# План работы (на следующие сессии)

## Схема
1. Пользователь присылает аудио (или видео) истории + текст. Большие файлы — ссылкой на Google Drive (gdown работает).
   Аудио должно быть его собственным (свой голос / своя ИИ-озвучка / свой текст). Чужие ролики не берём.
   Если аудио нет — озвучиваем сами Piper'ом (см. tools/README.md).
2. Распознаём речь с таймкодами слов (faster-whisper; нужен доступ к huggingface.co).
3. По тексту размечаем сцены: `[ночь, сундук, друг злой] текст…` → сцена из библиотеки + движение камеры.
4. Автонарезка на части по 30–35 сек по паузам; «Часть N», обрыв, призыв к продолжению.
5. Каждая часть: сцены (tools/scenes.py) + субтитры по слову + баннер ClipHub_games.mov сверху (STYLE.md).
6. Отдаём 10 mp4 + названия/описания с #funpay #cliphub.
