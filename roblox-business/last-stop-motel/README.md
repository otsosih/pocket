# Last Stop Motel: прототип (неделя 2)

Цель прототипа: проверить, интересно ли **искать аномалии**, пока в игре нет ни арта, ни монетизации.

## Что уже есть
- Серая (greybox) карта мотеля строится из кода: холл, коридор, 4 номера, около 20 предметов.
- **22 аномалии**: перевёрнутая картина, лишний стул, красная лампа, открытая дверь, табличка «13», «NO EXIT» и другие.
- Цикл ночи: 20 секунд запоминаешь мотель, затем 6 минут ночи (00:00 → 06:00 AM). Аномалии появляются всё чаще.
- Подойди к предмету и **удерживай E**, чтобы сообщить об аномалии.
  - Верно: аномалия исчезает, +10 Cash, запись в журнал.
  - Неверно: страйк.
- Ночь проиграна при **3 ложных репортах** или **4 незамеченных аномалиях одновременно**. Выжил до 6:00: +50 Cash.
- Сохранение прогресса (Cash, пережитые ночи, журнал аномалий) через DataStore. Есть защита от потери данных и от записи одного игрока с двух серверов.
- События аналитики: начало и исход ночи, верные и ложные репорты, получение Cash.

## Как запустить (самый простой способ)
1. Откройте файл `LastStopMotel.rbxlx` в Roblox Studio (двойной клик или File → Open).
2. Нажмите **Play** (F5).
3. Через 20 секунд начнётся ночь. Ходите по мотелю и ищите изменения.

Чтобы проверить **сохранение**, опубликуйте место (File → Publish to Roblox, можно приватно). Затем включите *Game Settings → Security → Enable Studio Access to API Services*. Без этого в Output будет предупреждение, а прогресс просто не сохранится. Это ожидаемо.

## Для разработки (позже, с Rojo)
Код живёт в репозитории, а Studio синхронизируется через [Rojo](https://rojo.space):
```
rojo serve default.project.json      # в Studio: плагин Rojo → Connect
rojo build default.project.json -o build/LastStopMotel.rbxlx
```

## Структура
```
src/shared/Config.luau             все настройки баланса
src/server/init.server.luau        точка входа сервера
src/server/MapBuilder.luau         greybox-карта; заменяется ручной картой с теми же PropId
src/server/AnomalyDefinitions.luau каталог аномалий (новый контент = новая строка)
src/server/AnomalyEffects.luau     переиспользуемые эффекты (сдвиг, цвет, размер, текст, свет)
src/server/AnomalyDirector.luau    серверная логика аномалий и репортов
src/server/ShiftService.luau       цикл ночи, страйки, награды
src/server/DataService.luau        сохранения (session lock, retries, autosave, BindToClose)
src/server/Analytics.luau          обёртка AnalyticsService
src/client/init.client.luau        HUD: часы, страйки, сообщения
```
