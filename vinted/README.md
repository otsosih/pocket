# Vinted — перепродажа

Память помощника. Claude читает этот файл в начале каждой новой сессии.

## Настройки
- Страна Vinted: Франция (vinted.fr)
- Валюта: EUR
- Где покупаю вещи: _не указано_

## Как работаем
1. Присылаю скрин вещи и цену покупки.
2. Claude ищет похожие объявления на Vinted, называет цену выставления, примерный срок продажи и прибыль.
3. Каждая сделка записывается в `deals.md`, после продажи туда же пишется итоговая цена.
4. По накопленным сделкам Claude подсказывает, что брать, а что пропускать.
